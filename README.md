# Marvel Marathon — Complete Companion

An independent fan-made Progressive Web App. Includes a multi-universe title library, watch progress, chronology views, character encyclopedia, teams/factions, and official-trailer search links.

## Publish
Upload the contents of this folder to the root of your GitHub Pages repository and commit. In GitHub Pages settings use `main` and `/ (root)`.

## Install
Open the published HTTPS site in Safari or Chrome and choose Add to Home Screen / Install app.

## Notes
- This is an unofficial fan project, not affiliated with Marvel, Disney, Sony, or 20th Century Studios.
- The library is a curated guide, not a claim to include every comic, adaptation, short, or regional release. Continuity labels and story chronology are editorial approximations.
- Trailer buttons open YouTube search results for official trailers; verify the channel before watching.
- Watch progress is stored locally on each device. There is no account or cloud sync.
